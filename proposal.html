Executive Summary

All Star Partners is pleased to present this proposal for ASP Secure IT®, our comprehensive managed security offering built for the realities of community health care.

FQHCs operate under demanding privacy and security obligations — HIPAA, HHS/OCR expectations, and 42 CFR Part 2 — while running lean IT teams across multiple locations. ASP Secure IT delivers enterprise-grade protection as a predictable monthly service, covering every site, user, identity, device, workstation, and server in your environment. Our team continuously monitors, patches, hardens, and defends your systems, and stands ready to respond when it matters most.

This engagement covers 4 sites, 300 users, 350 identities, 350 devices, 300 workstations, and 12 servers under a single, fully-managed program with the standard non-recurring onboarding charge waived.
02

Scope of Services

Your ASP Secure IT program is composed of the following managed service components, each billed per unit and delivered under a unified security operations model.

Per Site

ASP Secure IT® Managed Site

Perimeter and network security for each physical location — managed firewall, secure connectivity, network monitoring, and site-level threat detection.

Per User

ASP Secure IT® Managed User

People-centered protection including email security, anti-phishing, and ongoing security awareness training to reduce human-factor risk.

Per Identity

ASP Secure IT® Managed Identity

Identity and access management with multi-factor authentication, conditional access, and identity threat detection to stop account takeover.

Per Device

ASP Secure IT® Managed Device

Managed detection & response (EDR/MDR) across endpoints — continuous monitoring, isolation, and remediation of threats in real time.

Per Workstation

ASP Secure IT® Managed Workstation

End-to-end workstation lifecycle security — patch management, configuration hardening, encryption enforcement, and compliance reporting.

Per Server

ASP Secure IT® Managed Server

Server hardening, patching, backup validation, and 24×7 monitoring for the systems that keep clinical and business operations running.
